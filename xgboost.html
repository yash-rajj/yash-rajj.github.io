    <h1>Math Behind XGBoost</h1>

    <p>

      XGBoost (Extreme Gradient Boosting) is a powerful ensemble learning method based on decision trees and gradient boosting. It is designed to be highly efficient and scalable.

    </p>


    <h2>1. Objective Function</h2>

    <p>

      XGBoost optimizes the following regularized objective:

    </p>

    <blockquote>

      Obj = ∑<sub>i=1</sub><sup>n</sup> l(y<sub>i</sub>, ŷ<sub>i</sub>) + ∑<sub>k=1</sub><sup>K</sup> Ω(f<sub>k</sub>)

    </blockquote>

    <p>

      Where <code>l</code> is a differentiable loss function (like squared error), and <code>Ω(f)</code> is the regularization term:

    </p>

    <blockquote>

      Ω(f) = γT + ½ λ‖w‖²

    </blockquote>


    <h2>2. Taylor Expansion</h2>

    <p>

      To optimize the objective, XGBoost uses a second-order Taylor expansion:

    </p>

    <blockquote>

      Obj ≈ ∑<sub>i=1</sub><sup>n</sup> [g<sub>i</sub>f(x<sub>i</sub>) + ½ h<sub>i</sub>f²(x<sub>i</sub>)] + Ω(f)

    </blockquote>

    <p>

      Here, <code>g<sub>i</sub></code> and <code>h<sub>i</sub></code> are the first and second derivatives of the loss function with respect to predictions.

    </p>


    <h2>3. Tree Structure and Score</h2>

    <p>

      For a fixed structure of a tree, the optimal weight of a leaf node <code>j</code> is:

    </p>

    <blockquote>

      w<sub>j</sub>\* = - ∑g<sub>i</sub> / (∑h<sub>i</sub> + λ)

    </blockquote>

    <p>

      And the corresponding score (gain) of that node is:

    </p>

    <blockquote>

      Gain = ½ [ (∑g<sub>i</sub>)² / (∑h<sub>i</sub> + λ) ] - γ

    </blockquote>


    <h2>4. Regularization</h2>

    <p>

      Regularization controls complexity using <code>γ</code> (number of leaves) and <code>λ</code> (leaf weights). This helps prevent overfitting and improves generalization.

    </p>
